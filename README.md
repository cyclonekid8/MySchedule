# MySchedule Flutter App

## How to build on your Android phone using Termux

### Step 1 — Download this project
Download the myschedule.zip file and extract it to your Downloads folder.

### Step 2 — Open Termux and run:
```bash
bash ~/storage/downloads/myschedule/BUILD_ON_TERMUX.sh
```

### Step 3 — Wait ~10–15 minutes
The script will automatically:
- Install Flutter & Android SDK
- Fetch all dependencies
- Build your APK
- Copy it to your Downloads folder as **MySchedule.apk**

### Step 4 — Install
Tap **MySchedule.apk** in your Downloads folder.
Enable "Install from unknown sources" if prompted (one-time only).

## Features
- Weekly schedule view with time slots
- 9 colour-coded categories
- Mark as Done checkbox (per activity)
- Repeat/recurrence options
- Reminder notifications
- Notes with title & body, searchable
- Full calendar view
- Dark mode
